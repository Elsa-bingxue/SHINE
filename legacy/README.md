the original dataset notebooks, annotations, and standalone model scripts.
The historical code and numerical results are unchanged. The previous instructions are retained in
[README.original.md](README.original.md).

Use [the seven current section notebooks](../notebooks/README.md) for Figures
2–5. The older 300-epoch dynamic-loss workflow differs from the current
120-epoch revision settings and is not the default reproduction path.

The archived Metascape exports retain the original enrichment tables, figures,
and analysis settings. Two unused service-catalogue rows were omitted from each
HTML report, and macOS archive metadata was removed. These are presentation
changes only; all other retained files are byte-identical to the original export.
